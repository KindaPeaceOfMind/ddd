# ТСЖ «Стрельникова» — Система управления заявками

## 📋 Описание
Веб-приложение для управления заявками жильцов в ТСЖ.

## 🚀 Установка

1. Скопируйте файлы на сервер
2. Импортируйте `sql/install.sql` в MySQL
3. Настройте подключение к БД в `core/db.php`
4. Откройте сайт в браузере

## 📁 Структура проекта

```

├── index.php          # Главный роутер
```
